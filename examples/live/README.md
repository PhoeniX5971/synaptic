# Local provider demos

Preserved exploratory scripts moved from the repository root and `tests/`.
These are manual demos, not deterministic tests or supported API qualification.
Run deliberately from the repository root, for example
`.venv/bin/python examples/live/test_signal_live.py`.
They can contact configured providers/local Ollama, incur costs, and write files.
Some retain historical APIs and machine-specific paths; audit before use.
